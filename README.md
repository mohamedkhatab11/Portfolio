# Muhammad Khattab — Portfolio

A responsive personal portfolio built with plain HTML, CSS and JavaScript.

## Files
- `index.html` — portfolio content and structure
- `style.css` — responsive dark/cybersecurity design
- `script.js` — mobile navigation and placeholder link handling

## Before publishing
Replace the placeholder GitHub and LinkedIn links in `index.html`.

Search for:
- `Add your GitHub repository URL here`
- `Add your LinkedIn URL here`

You can also add:
- your real university name
- GitHub URLs for each project
- project screenshots
- certifications
- a PDF CV

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Publish free
### GitHub Pages
1. Create a GitHub repository.
2. Upload the three files.
3. Go to Settings → Pages.
4. Select the main branch and root folder.
5. Save.

### Vercel
1. Push the project to GitHub.
2. Import the repository into Vercel.
3. Deploy. No build command is required.
